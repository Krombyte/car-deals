# Roadmap

## Favorites

The old Mustang Picks tab is gone. Each person builds a Favorites list with the heart. A later version could still personalize Mustang imagery, but there is no shared default list.

## Later, not in this version

- A licensed valuation adapter (Kelley Blue Book, Black Book, or MarketCheck) once `VALUATION_API_KEY` is set. The site must not scrape those services.
- Cloud Storage for photos after the Firebase project moves to the Blaze plan. Until then, photos stay in Firestore.
- Another listing source only if its robots.txt and terms clearly allow automated reads of public inventory.
